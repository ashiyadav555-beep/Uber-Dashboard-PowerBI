# Uber Dashboard Analysis Using Power BI

## Project Overview
Developed an interactive Power BI dashboard to analyze Uber booking data and provide business insights.

## KPIs
- Completed Bookings
- Lost Bookings
- Revenue
- Total Distance
- Average Distance

## Dashboards
### Overview Page
- Monthly Analysis
- Quarterly Analysis
- Revenue by Vehicle Type
- Top Pickup and Drop Locations
- Rider & Driver Ratings

### Vehicle Page
- Booking Count
- Revenue
- Contribution Analysis

### Revenue Page
- Revenue by Customer
- Revenue by Vehicle
- Revenue by Payment Method

### Rider Page
- Cancellation Analysis
- Rider Segmentation
- Payment Analysis

### Location Page
- Total Distance
- Busy Time Slots
- Busy Areas

## Tools Used
- Power BI
- Excel
- DAX
